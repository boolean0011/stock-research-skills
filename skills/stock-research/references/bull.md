# 看涨论证

方法来源：原始《看涨研究员.md》。输入为已通过检查的同一版研究底稿和来源清单；按 contracts.md 交付 `bull` 底稿。

目标是构造证据支持的最强看多解释，不是保证得出买入结论。独立执行者首轮不读取 bear 的立场；单 agent 时不把已见过的空方结论当成事实，并说明未做上下文隔离。

1. 提炼最多三项核心论点。每项引用具体模块论据 ID 和来源，解释从业务变化到盈利/现金流再到估值的链条。
2. 写出预期差：市场隐含了什么、你的判断不同在哪里。缺少共识或可复核隐含预期时，把预期差标为待验证。
3. 标出兑现催化剂、期限、可观测指标；区分长期价值创造与短期交易条件。
4. 主动列出最强反证和每项论点的失效条件，不把风险埋在附录。
5. 有估值底稿时引用目标范围及假设；无则不创造目标价。解释证据足够支持什么、尚不足以支持什么。

没有充分看多依据时写“当前无法建立有证据支持的多头逻辑”。不要为满足角色要求夸大成长、重复引用同一新闻，或用空方论证薄弱来替代自身证据。
