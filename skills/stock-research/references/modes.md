# 运行模式与依赖

## full：个股完整研究

用于“按整套 prompt 研究”“六路分析加多空裁决”等请求。

依赖图：输入与公共来源 → market / industry / fundamentals / technical / news / social → 检查 → bull / bear → synthesis → 最终校验。

所有模式中，只要执行多空论证，就分别以看涨研究员和看跌研究员两个角色交付底稿，再由综合裁决者整合；委派与上下文隔离按 [主流程 D 节](../SKILL.md#d-多空论证与综合裁决) 执行。

六路可以使用共享底稿分别执行，不依赖彼此的立场。行业或市场结论如被其他模块引用，必须记录引用，不能让下游研究悄悄改变上游事实。

所有已选研究模块写出结果后再进入检查，即使部分结果只是 blocked 及缺口说明。缺少社媒资料时可继续；缺少核心公司披露或估值输入时仍能总结已知内容，但限制投资裁决，不能补造目标价。

用户主动缩小范围时尊重选择，列明未覆盖模块。不能把缩减范围写成已经执行完整六路。

## update：专项更新

用于指定新闻、财报、技术等变化的复核。先确定是否存在可读取的 previous_run：

- 有：读取原始输入、来源清单、相关模块及最终结论，确认同一证券和研究期限。新增运行目录，保留旧目录。
- 无：做独立专项分析，明确“没有前次底稿，无法判定相对变化”；不为了缺少基线自动扩展成完整研究。

只加载所需研究模块。未指定专项但有前次底稿时，先比较原研究范围内的新事实，再更新受影响模块；既无基线又无关注点时，询问本次要更新的范围。原模块可以作为背景复用，但保留原截止时间，并检查是否还适用：价格、技术指标和短期情绪不能冒充本次最新值。来源沿用旧编号时同时导入旧条目，新条目续号。

更新传播按实际影响决定：

| 变化 | 需要复核的下游 |
| --- | --- |
| 新财报、指引、收入或毛利假设 | fundamentals；如影响行业比较则 industry；bull、bear、synthesis |
| 政策、客户、订单等重要新闻 | news；验证受影响的 fundamentals/industry；bull、bear、synthesis |
| 仅价格或技术结构变化 | technical；更新短期条件，保留长期论点并注明未重估；需要交易裁决时再复核双方 |
| 仅社媒噪声、无新事实 | social；说明证据不足以改变投资逻辑，不强行扩展财务结论 |

`checks.md` 记录变化清单、保留的旧假设、可能过期的模块，以及是否需要重新论证。用户只要求事实更新时不强行给买卖结论。

输出使用研究报告模板，突出“新增事实、原假设是否受影响、仍未覆盖的部分”。全套旧研究无从重建时，不声称重新完成完整六路。

## weekly：AI 周期与组合周报

阅读 [周度研究指令](weekly.md)。依赖：时间与观察范围 → market + news + 周度 AI 证据 → 相关行业/公司/技术复核 → 检查 → 周度情景与行动条件 → 周报校验。

默认不是对观察清单每只股票都跑 full。只对本周有重大变化、用户持仓或用户特别关注的标的深化；对它们读取对应研究模块，必要时增加 bull/bear/synthesis。社媒仅在可得且能解释拥挤度时添加。

缺少 positions 仍可做市场和观察清单复盘，持仓段落写“未提供持仓，未评估个人组合”。上一期不存在时不计算环比评分，也不声称本周风险上升或下降，除非有同口径历史数据支持。

## 资源与停止规则

先完成可验证核心信息，再增加细节。不为填满所有评分栏位无限搜索。工具无法访问或关键数据不可得时，说明覆盖与限制并降级；需要用户提供的资料由一个合并问题询问。

任何模式都不能在未核验数据时变成确定性交易指令。用户要求迅速完成时缩小覆盖并标记，不取消来源和时间边界。
