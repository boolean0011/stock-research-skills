# 美股研究编排

组织美股完整研究、指定模块更新和 AI 周度复盘，按所选模式收集证据、检查假设并交付报告。需要多空论证时，由看涨研究员与看跌研究员分别执行，再完成综合裁决。研究方法见下方模块指令；不把角色头衔、尖锐语气或强制评分当作证据。

这是由宿主 agent 执行的指令式工作流，不是独立的行情服务、交易程序或定时调度器。

## 开始前

1. 阅读 [输入、来源与输出契约](references/contracts.md) 和 [运行模式](references/modes.md)，确认本次模式、标的、截止时间和研究周期。只询问会改变研究对象或结论的缺失信息。
2. 使用已安装的 Public Equity Investing 时，先阅读 [能力复用规则](references/integration.md)。复用其专业研究与校验方法；本 Skill 负责模块依赖、公共事实底稿和最终整合。不假定安装插件就拥有金融数据库访问权。
3. 告知执行范围、默认假设及主要数据限制。默认中文、Markdown；用户指定输出格式优先。
4. 创建独立运行目录，记录输入和模块状态。用户提供的资料（含研究指令和持仓文件）及先前运行目录保持不变。

## 三种运行模式

完成“开始前”后，在 `request.json` 中确定 `mode`，然后按下表对应行执行。表中的 A、B、C、D 分别指向下方“通用执行规则”的同名步骤；详细范围与更新传播规则见 [运行模式](references/modes.md)。

| 模式 | 何时使用 | 选定模式后如何执行 |
| --- | --- | --- |
| 完整研究 `full` | 要求整套六路研究与投资判断 | 按下方 **A → B → C → D** 顺序执行；B 启用全部六个研究模块，D 必须执行；随后进入 [完成与恢复](#完成与恢复)，交付研究报告。 |
| 专项更新 `update` | 基于上次报告更新指定内容、判断原投资逻辑是否变化 | 先读取可用的上次报告与相关底稿，再按下方 **A → B → C** 执行；B 只更新指定或受影响模块。C 判定需要重新论证投资逻辑时执行 **D**，否则跳过 D；最后均进入 [完成与恢复](#完成与恢复)，交付更新报告。 |
| 周度复盘 `weekly` | 回顾一个美股交易周、AI 周期及持仓或观察清单 | 先确认交易周与观察范围，再按下方 **A → B → C** 执行；B 覆盖市场、新闻、AI 周期及重点标的复核。需要多空论证的标的在 C 后进入 **D**；随后按 [周度研究指令](references/weekly.md) 整合下周情景与观察条件，进入 [完成与恢复](#完成与恢复)，交付周报。 |

专项更新的 C 步骤需在 `checks.md` 记录新事实对原假设的影响，以及执行或跳过 D 的理由。仅做事实更新时不强行开展多空论证。没有上次报告时可做独立专项分析，但不能声称判断了相对变化。

周度复盘默认覆盖最近一个完整美股交易周，C 步骤记录哪些标的需要进入 D；无需多空论证时，C 后直接整合周度情景与观察条件。未提供持仓时只分析市场与观察清单，不推断个人仓位，也不默认对每个标的执行完整研究。

## 通用执行规则

下方 A–D 是模式表中引用的具体执行步骤。按已选模式指定的顺序、模块范围和分支条件进入对应步骤；`full` 必须执行 A–D，`update` 与 `weekly` 在 C 后按各自条件决定是否进入 D。

### A. 建立公共事实底稿

核验公司、证券类型、交易所、币种和时间边界。按任务取得最小足够的公司披露、行情、宏观或事件资料，并建立 `sources.md`。需要时再补充，不先扫全市场。

同一轮研究共享价格时间戳、财报口径和来源编号。对于历史截止时间，只用当时已公开的信息；不能确认可得时间的资料标为限制，不用于声称历史可交易的结论。

### B. 执行研究模块

按所选模式读取下面对应的文件，未选中的模块不加载。完整研究默认六路全选。

`weekly` 在本步骤还须执行 [周度研究指令](references/weekly.md) 中的市场与 AI 周期证据分析，并按重点标的需要加载行业、基本面或技术等模块；下周情景与观察条件在 C 检查及必要的 D 执行后整合。

| 模块 ID | 研究指令 | 输出 |
| --- | --- | --- |
| market | [市场研究](references/market.md) | 宏观、流动性、广度、估值与近期风险 |
| industry | [行业研究](references/industry.md) | 周期、竞争、增长驱动与行业 KPI |
| fundamentals | [基本面研究](references/fundamentals.md) | 商业模式、护城河、盈利质量、订单与增长假设 |
| technical | [技术研究](references/technical.md) | 日周趋势、均线、关键价格位与失效条件 |
| news | [新闻研究](references/news.md) | 事件、财务传导与投资逻辑变化 |
| social | [社媒研究](references/social.md) | 有样本依据的情绪观察与覆盖限制 |

前置六路研究默认由总控 agent 分阶段执行；用户要求或宿主明确允许委派时，也可分派互不依赖的模块。各执行者共享已锁定的输入与来源快照，仅写自己的模块文件，来源由总控去重合并。看涨与看跌的角色分工按 D 节执行。

### C. 完成证据检查

所有已选的前置研究模块必须有输出和终态，才能进入后续论证或报告交付；此门槛不包括尚待执行的 bull、bear、synthesis。`degraded`、`blocked` 也要说明原因，不能把无数据伪装成研究完成。

核对标的、币种、日期、会计期间、GAAP/non-GAAP、来源可追溯性与重复新闻。把不同事实口径和同一事实的不同解释分开处理。事实矛盾先查原始来源；未解决的冲突保留在 `checks.md` 并降低结论强度。

完成检查后，`full` 进入 D；`update` 和 `weekly` 按模式表及 `checks.md` 中记录的判断，进入 D 或各自的后续交付路径。

### D. 多空论证与综合裁决

完整研究，以及需要重新论证投资逻辑的专项更新，执行以下步骤；周度模式中需要多空论证的标的也遵循同一分工。看涨研究员、看跌研究员和综合裁决者分别承担论证与裁决职责，不能把一段总判断拆成“看涨/看跌”标题充当两个角色的执行。

1. 冻结本次可用研究底稿和来源版本；专项更新同时标明新底稿、复用的旧底稿及未覆盖部分。双方使用同版事实、来源、研究期限和覆盖限制。
2. 将 [看涨论证](references/bull.md) 分配给“看涨研究员”，将 [看跌论证](references/bear.md) 分配给“看跌研究员”。有可用委派工具时，分别由两个不同子 agent 执行，可并行或顺序运行；为双方提供各自角色指令及同版公共底稿，使用不含对方论证或预先裁决的新上下文。首轮不互读输出，各自交付 `bull`、`bear` 底稿。宿主不支持委派时，仍须分两个角色阶段分别执行和保存底稿，记录为“单 agent 分角色执行”，说明上下文未隔离，不声称独立双 agent 验证。
3. 不为了平衡篇幅强造论据。论证提出的新事实由总控回到来源清单核验，再同步给双方，由各自角色更新底稿；不得仅在一方的论证中加入未经核验的数据。
4. 双方底稿均有实际输出和终态后，总控以“综合裁决者”身份阅读 [综合裁决](references/synthesis.md)，对最影响结论的分歧逐项裁决，不在裁决阶段代写双方论证。缺项按实际覆盖说明。一次定向补证仍无法解决时，报告分歧和限制，不无限辩论。

完成 D 后，`full` 与 `update` 进入 [完成与恢复](#完成与恢复)；`weekly` 将相关标的的裁决纳入周度情景与观察条件，再进入报告交付。

## 数据与行动边界

- 动态数据需要本次可核验来源；不能从模型记忆补价格、共识、社媒比例或订单数字。
- 无法联网但有用户资料时，只做限定于资料的分析；没有可靠数据时交付缺口清单和研究计划，不给实时判断或假目标价。
- 缺少社媒或期权数据只限制相关模块，不阻塞已有证据支持的其他研究。数据缺失不等于中性信号，也不等于零风险。
- 评分必须说明量表、样本与主观性；概率不是统计胜率。估值目标、技术价位、风险止损分别列示。
- 不以“六路同向”简单投票：新闻与社媒可能重复放大同一事件。
- 不默认用户持有任何股票。没有组合约束时给条件式研究意见，不给个性化仓位、具体期权合约或卖空数量。
- 本流程只研究，不下单、不修改账户、不发布报告。周度复盘的参考时间不构成创建自动化的授权；定时运行需用户另行明确要求。

## 完成与恢复

完整研究和专项更新使用 [研究报告模板](assets/research-report.md)，周度复盘使用 [周报模板](assets/weekly-report.md)。删除不适用的模板段落，不留未填写占位符；已执行多空论证时，说明各角色的实际执行方式与上下文隔离情况。

结束前按 `contracts.md` 的完成门槛检查报告、来源、状态与限制。交付时首先链接最终报告，说明哪些模块缺数据，以及哪些结论可能因此改变。

中断后先读 `request.json`、`progress.json` 和已有文件，核对截止时间与输入是否一致。只恢复未完成步骤；需要刷新数据或变更范围时创建新运行，不混入旧快照。文件已保存不等于研究已通过校验。

## 调用示例

- 完整研究 `full`：“使用 $us-equity-research 完整研究 NVDA，关注未来 6–12 个月的投资逻辑，同时单列未来 10 个交易日的技术条件。”
- 专项更新 `update`：“使用 $us-equity-research，基于我提供的上次报告，只更新 NVDA 的新闻和基本面，判断原投资逻辑是否变化。”
- 周度复盘 `weekly`：“使用 $us-equity-research 做截至最近完整美股交易周的 AI 周度复盘；观察 QQQ、SMH、NVDA，我没有提供持仓，不要推断仓位。”
